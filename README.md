# Campus Guide - 학적변동 절차 내비게이터

학생이 자신의 상황을 자연어로 입력하면 휴학·자퇴·복학·재입학·전과 절차를 찾고, 필요한 조건을 추가로 확인한 뒤 공식 안내에 기반한 처리 순서·서류·주의사항·담당 부서를 보여주는 실시간 시연 프로토타입입니다.

## 실행 방법

```powershell
npm.cmd install
npm.cmd run dev
```

브라우저에서 `http://127.0.0.1:5173/`을 엽니다.

## 배포 주소

- Firebase Hosting: https://campusguide-jaeheon.web.app/

## 검증 명령

```powershell
npm.cmd run verify
```

`verify`는 문의 분석·복합 절차·상황별 결과 테스트와 프로덕션 빌드를 실행합니다. 별도의 lint 명령은 구성되어 있지 않습니다.

## 구현 범위

- 개인정보 없는 자연어 상황 입력
- 휴학·자퇴·복학·재입학·전과 5개 학적변동 절차
- 행정 용어를 사용하지 않은 일상 표현 분석
- 최대 3개 절차가 포함된 복합 문의의 선후관계 안내
- 단과대학, 휴학 유형, 등록금·장학금, 군 복학 등 필요한 조건 확인
- 상황별 신청 조건, 필요 서류, 처리 순서와 주의사항
- 단과대학별 교학팀·공식 대표번호·위치
- 강남대학교 공식 안내·규정집·통합전화번호부 원문 링크
- 빈 입력, 지원 범위 밖 문의, 결과 생성 오류와 다시 입력
- 모바일 및 키보드 접근성 대응

## 시연 추천 문장

- `군 복무를 마치고 다음 학기에 복학하려고 합니다. 어떤 서류를 준비해야 하나요?`
- `2년 전에 자퇴했는데 다시 학교에 다니고 싶습니다. 재입학이 가능한가요?`
- `등록금은 이미 냈고 장학금도 받았습니다. 개인 사정으로 이번 학기를 휴학하려면 어떤 절차가 필요한가요?`
- `이번 학기 등록금을 낸 상태에서 자퇴하려고 합니다. 필요한 서류와 등록금 반환 절차가 궁금합니다.`
- `현재 휴학 중입니다. 다음 학기에 복학하면서 다른 학과로 전과하려면 무엇부터 해야 하나요?`
- `이번 학기에 휴학하고 다음 학기에 복학한 뒤 전과하려면 어떤 순서로 진행해야 하나요?`

## 데이터와 안전 기준

- 공개된 강남대학교 공식 페이지를 2026-07-24 기준으로 사람이 구조화한 시연 데이터입니다.
- 실제 AI API, 학교 내부 시스템, 로그인과 문의 저장은 연결하지 않았습니다.
- 공식 원문이 변경되거나 서로 다를 경우 최신 원문과 담당 부서의 판단을 우선합니다.
- 학생 개인의 신청 가능 여부를 확정하지 않으며, 판단에 필요한 조건과 최종 확인 지점을 안내합니다.
- 이름·학번·전화번호 등 실제 개인정보를 입력하지 마세요.

## 디자인과 글꼴

- 흰색·회색 바탕, 한 가지 파란색 강조, 큰 제목과 넓은 여백을 사용해 핵심 흐름의 가독성을 높였습니다.
- 화면 글꼴은 Google Fonts의 `Noto Sans KR`을 사용하며, 이 글꼴은 SIL Open Font License 1.1로 배포됩니다.
- 웹 글꼴을 불러오지 못해도 운영체제 기본 한글 산세리프 글꼴로 표시됩니다.

## 구현하지 않은 범위

- 실시간 학교 규정·공지 자동 수집
- 실제 AI 또는 RAG
- 로그인·문의 이력·개인별 학적 연동
- 자동 신청·서류 제출·담당자 연결
- 휴학·자퇴·복학·재입학·전과 이외의 전체 교내 행정 절차
