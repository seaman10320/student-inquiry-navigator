# 바로문의 — 학생 문의 길잡이

학생이 자연어로 학교 행정 문의를 입력하면 가상 담당 부서와 문의 정보를 보여주는 P0 프로토타입입니다. 실제 AI나 학교 행정 시스템은 연결하지 않았으며, 모든 부서명·연락처·서류·링크·절차는 시연용 가상 데이터입니다.

## 실행 방법

Node.js가 설치된 환경에서 이 폴더를 터미널로 연 뒤 실행합니다.

```powershell
npm.cmd install
npm.cmd run dev
```

브라우저에서 `http://127.0.0.1:5173/`을 엽니다.

## 검증 명령

```powershell
npm.cmd run verify
```

`verify`는 규칙 기반 분류 테스트와 프로덕션 빌드를 차례로 실행합니다. 이 프로젝트에는 별도의 lint 명령이 없습니다.

## P0 구현 범위

- 개인정보 없는 자연어 문의 입력과 가상 예시
- 빈 입력 안내
- 휴학·복학·장학·증명서 문의의 규칙 기반 분류
- 가상 담당 부서, 전화번호, 이메일, 문의 가능 시간, 위치, 필요 서류, 신청 링크와 처리 절차 표시
- 분류 실패 시 가상 대표번호 안내
- 결과 확인 후 다른 문의로 초기화
- 가상 데이터·규칙 기반 시뮬레이션 표시
- 모바일 폭 대응

## 구현하지 않은 범위

- P1: 추가 가상 문의 유형과 부서 데이터 확장
- P2: 실제 AI, 실제 학교 데이터, 로그인, 실시간 채팅, 문의 이력, 자동 전화 연결, 학교 내부 행정 시스템 연동

실제 이름·학번·전화번호 등 개인정보를 입력하지 마세요.
